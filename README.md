## Skills covered

Rough map of topics I touch across these boxes. Marks track how comfortable I am: `+` did it with hints, `++` solo but slow, `+++` solo and fast.

**Recon and enumeration**
Nmap, service enumeration, banner grabbing, content discovery, Gobuster, SMB/SNMP enumeration

**Web**
SQLi, XSS, CSRF, IDOR / access control, SSRF, file upload, path traversal, command injection, business logic, JWT, authentication attacks

**Password attacks**
Wordlists, Hashcat, John, Hydra, hash identification

**Exploitation**
Metasploit, msfvenom, reverse and bind shells, public exploit usage

**Privilege escalation**
Linux enumeration and privesc, Windows privesc, config reviews

**Crypto and hashing**
Symmetric vs asymmetric, RSA, hashing, salting, encoding vs encryption
